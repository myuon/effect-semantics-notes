## Status

**Semantic construction and hypothesis audit.**  This page builds the free
operation layer over the Chapter-I base semantics.  The operation tree is a
denotational structure, not the static effect annotation and not a runtime
trace model.

## 1. Signature functor

For an interface family $\Sigma$, define the polynomial operation functor

$$
\Sigma X
=
\coprod_{\Delta\in\mathcal D}
\coprod_{i\in I_\Delta}
P_i\times X^{R_i}.
$$

An element consists of an operation parameter and a continuation indexed by
the operation's response type.

## 2. Ungraded mnemonic

Suppressing grades temporarily, the standard finite free extension is
mnemonically
initial solution

$$
\mathsf F_\Sigma(T)A
\cong
T\bigl(A+\Sigma(\mathsf F_\Sigma(T)A)\bigr).
\tag{FreeT}
$$

Intuitively, the outer $T$ performs a finite piece of base computation.  It
then either returns an $A$ or exposes one free operation whose responses lead
to further extended computations.

For the recursion-free source calculus, it is enough to use the finite initial
algebra generated by source terms.  Chapter IV will revisit recursive domain
solutions; no such assumption is needed here.

This equation is not the formal grade-indexed carrier.

## 3. Ordered grading

The formal carrier is an initial algebra in the indexed-family category
$\mathcal C^{\widehat E}$.  Its layer functor records a base prefix $b$ and
either a return with $b\le d$ or a request decomposition
$b\cdot\Delta\cdot e\le d$.  The complete definition is given in
[Grade-indexed free carrier](grade-indexed-free-carrier-v5.md).

It is indexed over

$$
\widehat E=B*\mathcal D^*.
$$

Write

$$
\mathsf F_eA
$$

for extended computations admitted by upper bound $e$.  The constructors have
the following grades:

$$
\mathsf{return}:A\to\mathsf F_1A,
$$

$$
\mathsf{lift}_b:T_bA\to\mathsf F_bA,
$$

$$
\mathsf{op}_{\Delta,i}:
P_i\times(R_i\to\mathsf F_eA)
\to\mathsf F_{\Delta\cdot e}A,
$$

and weakening gives

$$
e\leq e'\Longrightarrow\mathsf F_eA\to\mathsf F_{e'}A.
$$

The operation constructor includes a continuation semantically even though the
source operation does not.  The source denotation of
$\mathsf{op}_{\Delta,i}(V)$ uses the identity continuation
$r\mapsto\mathsf{return}\,r$; source `let` later composes the surrounding
continuation by bind.

## 4. Return and bind

The free extension has graded bind

$$
\mathsf F_eA
\times
(A\to\mathsf F_fC)
\longrightarrow
\mathsf F_{e\cdot f}C.
$$

It is defined by the initial-algebra recursion:

- substitute into returns;
- use base graded bind through the outer $T$;
- preserve each free operation and compose into every response continuation.

The graded unit and associativity laws follow from initiality together with a
coherent `baseAct` and the base graded monad laws.  The action may be supplied
directly or obtained from the
[root-exposure construction](base-action-construction-v5.md).  The
construction is strong when $T$ is strong, the action respects strength and
the polynomial initial algebras are stable under the required products.

## 5. Base embedding and conservativity diagram

There is a canonical graded embedding

$$
j_b:T_bA\to\mathsf F_bA
$$

that performs the base computation and returns its value without introducing a
free node.  It preserves unit, bind, strength and weakening.

For every old Chapter-I term $M:A!b$, the intended diagram is

$$
\llbracket M\rrbracket_{\mathsf F}
=
j_b\circ\llbracket M\rrbracket_T.
\tag{Free-Conservativity}
$$

This is proved by induction on the old typing derivation.  It is the
denotational half of base conservativity.

## 6. Interpretation of the new syntax

If

$$
v:\llbracket\Gamma\rrbracket\to P_i,
$$

then

$$
\llbracket\mathsf{op}_{\Delta,i}(V)\rrbracket
=
\mathsf{op}_{\Delta,i}
\bigl(v,\lambda r.\mathsf{return}\,r\bigr)
\in\mathsf F_\Delta R_i.
$$

`let` is interpreted by graded bind, so

$$
\llbracket
\mathbf{let}\ x\leftarrow\mathsf{op}_{\Delta,i}(V)
\ \mathbf{in}\ N
\rrbracket
$$

is the same operation node with continuation
$r\mapsto\llbracket N[r/x]\rrbracket$.

Conditionals use categorical case analysis after both branches are weakened to
their common static bound.  No semantic branch union is required.

## 7. Concrete instances

### Writer

Take the upper-bound Writer $T_b$ from Chapter I.  An extended denotation is a
finite tree whose base segments accumulate Writer logs and whose free nodes
remain visible.  For

```text
tell_a; ask; tell_b
```

the denotation has a Writer prefix $[a]$, an `ask` node, and a continuation
whose Writer denotation contributes $[b]$ after a response.

### State

With $T_bA=S\to A\times S$, the outer base layer threads state up to a free
node.  Each response continuation is again stateful.  The denotation of the
`get; choose; put` example passes the value read by `get` to the `choose`
parameter and applies `put` only inside the response continuation.

### Exception

With $T_bA=A+\mathsf{Err}$, an exception in the outer base layer prevents the
sum branch containing a later free node from being reached.  Conversely, a
free node may have an exception-raising continuation.  This matches the two
direct calculations without adding any generic abort marker.

## 8. Required hypotheses

The free extension requires more than the bare monad laws only where stated:

- the indexed layer endofunctors $\mathcal H_A$ must have initial algebras in
  $\mathcal C^{\widehat E}$;
- base strength is needed for open CBV terms;
- coherent base weakening must extend to $\widehat E$;
- the chosen observation must be enlarged to distinguish an exposed free
  request from an ordinary base result.

No inspection operation $T_bA\to A+\Sigma(-)$ is required.  Free nodes are
introduced outside $T$ by the resumption construction.
