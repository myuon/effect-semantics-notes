# Categories of extensible semantic packages

:::{admonition} Formalization status — categorical layer
:class: note
**Lean-checked categorical skeleton.** The chosen graded models and base
actions are bundled by
[`ExtensibleGradedPackage`](https://myuon.github.io/effect-semantics-notes/lean/find/?pattern=EffectSemantics.ExtensibleGradedPackage#doc).
Compatible arrows, including the `Act-Morphism` square, form a category, and
selecting the chosen extension is the Lean-checked functor
[`gradedFreeExtensionFunctor`](https://myuon.github.io/effect-semantics-notes/lean/find/?pattern=EffectSemantics.gradedFreeExtensionFunctor#doc).
Existence of the indexed initial algebra and the full graded monad/action laws
remain object-side hypotheses rather than consequences of this packaging.
:::

## Status

**Formal categorical boundary for the recursion-free theorem.**  The
functorial statement compares denotational implementations of one fixed source
language, effect algebra and observation interface.  It is not yet a functor
between arbitrary programming languages.

## 1. Fixed parameters

Fix:

1. a recursion-free base syntax and machine $L_B$;
2. a base signature $\Sigma_B$;
3. an ordered base effect monoid $E_B$ and its extension $\widehat E$;
4. a finite-response monad $\mathcal K$;
5. ground observation objects and an operational run map;
6. a new first-order interface $\Delta$.

Fixing these data ensures that two semantic models interpret the same types,
grades, primitives and observations.

## 2. Source category

Define the structural category $\mathbf{ExtBase}^{\mathrm{str}}_\Delta$ as
follows.

### Objects

An object is a strong $E_B$-graded model $T$ such that:

1. $\mathsf{BaseModelCert}(L_B,E_B,T)$ holds;
2. the indexed layer functors $\mathcal H_A^T$ have the required initial
   algebras;
3. the resulting carriers carry a coherent base action;

Thus the category contains **extensible base packages**, not every graded
monad.

### Morphisms

A morphism $q:T\to U$ is a grade-indexed natural transformation

$$
q_{e,A}:T_eA\to U_eA
$$

satisfying:

1. preservation of graded return and multiplication;
2. preservation of strength;
3. commutation with every weakening map;
4. preservation of every base primitive;
5. the base-action square `(Act-Morphism)` for the fold induced by the layer
   map generated from $q$.

The fifth condition is not circular: indexed initiality first supplies the
unique carrier fold generated by $q$ on returns, old layers and new
generators.  The condition then asks whether that fold commutes with the two
chosen base actions.  Only folds passing this test are admitted as source
morphisms.

Equality of morphisms is componentwise equality of $q_{e,A}$.

Identity transformations satisfy all five conditions. Conditions are closed
under componentwise composition, so these data form a category.

The observed subcategory
$\mathbf{ExtBase}^{\mathrm{obs}}_{\Delta,\mathcal K}$ additionally requires
`BaseSafetyCert`, `BaseAdequacyCert`, a finite-response certificate for
$\mathcal K$, the canonical separated pole, and observation preservation by
morphisms. These fields are needed for adequacy transport, not for the free
extension functor itself.

## 3. Target category

Define $\mathbf{Free}^{\mathrm{str}}_\Delta$ to have:

- objects $\mathsf F_\Delta(T)$ carrying the carrier and monadic parts of
  `FreeCert`;
- morphisms grade-indexed transformations preserving extended return, bind,
  strength, weakening, old base layers, new $\Delta$ generators and the
  base action.

Again, equality is componentwise.

## 4. Functor

:::{prf:theorem} `[PKG.4.1]` Package-level free-extension functor [[Lean]](https://myuon.github.io/effect-semantics-notes/lean/find/?pattern=EffectSemantics.gradedFreeExtensionFunctor#doc)
:label: thm-package-free-functor-v5

The assignments

$$
T\longmapsto\mathsf F_\Delta(T),
\qquad
q\longmapsto\mathsf F_\Delta(q)
$$

define a functor

$$
\mathsf F_\Delta:
\mathbf{ExtBase}^{\mathrm{str}}_\Delta
\to
\mathbf{Free}^{\mathrm{str}}_\Delta.
$$
:::

**Proof.** Object well-definedness is the carrier/monadic part of
`Free-Transport`. Indexed initiality defines the arrow map; primitive and
base-action compatibility ensure it is a target morphism. Lean checks that
the embedding and action squares hold for identities and are closed under
composition, and then checks both functor laws. The initial-algebra argument
that constructs each chosen object is deliberately a premise of this
categorical layer. $\square$

## 5. Relations are not morphisms

A heterogeneous logical relation

$$
R_{e,A}\subseteq T_eA\times U_eA
$$

is handled in the relation fibration over
$\mathbf{ExtBase}^{\mathrm{str}}_\Delta\times
\mathbf{ExtBase}^{\mathrm{str}}_\Delta$, not inserted as another kind of arrow
in the category above.

An object of the relevant fibre is a graded relator
$\overline{T,U}_b(R)$. The structural lifting is fibrewise:

$$
\overline{T,U}\longmapsto\mathsf{Str}_\Delta(\overline{T,U}).
$$

For a genuine morphism $q$ whose base relator satisfies `(Rel-Graph)`, the
graph object in that fibre satisfies

$$
\mathsf{Str}_\Delta(\overline q)
=\operatorname{Graph}(\mathsf F_\Delta q).
$$

The graded TT construction is a closure operation in the same fibre and may
strictly enlarge this graph.

## 6. Handler naturality

Handler naturality is not part of $\mathsf F_\Delta$ itself.  After selecting
handler families $h_T,h_U$ and a result morphism $q_h$, the clause
compatibility conditions imply the square

$$
\begin{CD}
\mathsf F_\Delta(T) @>{\mathsf{sh}_{h_T}}>> H_T\\
@V{\mathsf F_\Delta(q)}VV @VV{q_h}V\\
\mathsf F_\Delta(U) @>>{\mathsf{sh}_{h_U}}> H_U
\end{CD}
$$

commutes.  Thus shallow handling is a natural transformation only for a
chosen compatible family of handlers and result carriers.

## 7. Boundary

If base languages, effect monoids or observations vary, one needs a larger
indexed category or fibration carrying translations between them.  The
current theorem deliberately fixes these parameters.  It therefore answers
representation independence and semantic extensibility for one language, not
cross-language compilation correctness.
