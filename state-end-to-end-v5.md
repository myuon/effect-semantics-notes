# State end-to-end certificate instance

## Status

**Concrete recursion-free derivation.**  This instance checks that the generic
construction does not depend on Writer prefix accumulation.

## 1. Base package

Let the store be $S$ and use

$$
T_bA=S\to(A\times S),
\qquad \mathcal K=\mathsf{Id}.
$$

Grades are ordered words generated by `read` and `write`; the carrier is
phantom-graded.  `get` and `put` have their usual global-state semantics.
For every initial state $s$,

$$
\langle M,s\rangle\Downarrow\langle\mathsf{return}\,v,s'\rangle
\quad\Longleftrightarrow\quad
\llbracket M\rrbracket(s)=(v,s').
$$

This supplies `BaseCert` pointwise in $s$.

## 2. Free `choose` and base action

Add

$$
\mathsf{choose}:\mathsf{Bool}\to\mathsf{Bool}
\quad\in\Delta.
$$

Finite state/free trees form the indexed initial algebra.  For

$$
u:S\to(\mathsf F_dA\times S),
$$

define $\mathsf{act}_{b,d}(u)$ by running $u$ at the incoming state, obtaining
$(t,s')$, and continuing the first stateful segment of $t$ from $s'$.  State
bind proves `Act-Unit`, `Act-Mult` and strength coherence.

The canonical extended observation is indexed by the initial state.  An
exposed request records its parameter, request-time state and a response
continuation to the next observation.

## 3. Calculation

Consider

```text
let old <- get(*) in
let answer <- choose(old) in
let _ <- put(answer) in
return old
```

with bound

$$
\mathsf{read}\cdot\Delta\cdot\mathsf{write}.
$$

From initial state `true`, both machine and indexed denotation expose

$$
\mathsf{chooseObs}
(\mathsf{true},\mathsf{true},
 \lambda r.\mathsf{returnObs}(\mathsf{true},r)).
$$

The first Boolean is the parameter, the second the request-time store, and the
continuation returns the old value after setting the store to $r$.

## 4. State-indexed TT pole

Define

$$
C\mathrel{\mathcal O^S_e}t
\quad\Longleftrightarrow\quad
\forall s.\quad
\mathsf{run}(C,s)=\mathsf{observe}(t,s).
$$

Return, `get`, `put` and free-node closure are pointwise in the initial state.
Bind closure uses the intermediate state produced by the related first
computations.  Weakening changes no state transformer.  Hence `TTCert` and the
structural-to-TT inclusion hold without any Writer-specific invariant.

## 5. Shallow handler

Use

```text
return x      -> return x
choose(p, k)  -> k false
```

The response is pure, so

$$
\mathsf{read}\cdot\Delta\cdot\mathsf{write}
\longmapsto
\mathsf{read}\cdot\mathsf{write}.
$$

At initial state `true`, operational and denotational execution both return
`true` with final state `false`.  `TTClause` follows by applying pointwise
related continuations to the same response at the same request-time state.

Thus the complete recursion-free certificate chain holds for State.
