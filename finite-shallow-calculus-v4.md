# Finite shallow calculus v4

## Status

**Fixed Chapter I core.**  This page consolidates the intended matcher from the
earlier ordered exploration into the new base-package program.

## 1. Base interface

A `FiniteBasePackage` supplies:

1. fine-grain CBV values and computations;
2. typed base primitives $\beta:P_\beta\to R_\beta$;
3. deterministic evaluation of closed base computations;
4. termination at a value or a classified base outcome;
5. substitution, preservation and residual-context typing;
6. an operational observation $\mathsf{obs}_B$;
7. optionally, a denotational model and a certificate relating it to
   $\mathsf{obs}_B$.

Termination is the Chapter I assumption that will be removed in Chapter II.
The base effect annotation $b$ is left instance-specific.  The newly added
free-effect annotation is a separate finite unordered may-row $\rho$.

## 2. Free operations

For each nominal interface $\Delta$, fix a finite signature

$$
\Sigma(\Delta)
=
\{\mathsf{op}_{\Delta,i}:P_i\to R_i\}_{i\in I_\Delta}.
$$

The source expression $\mathsf{op}_{\Delta,i}(V)$ has result type $R_i$.
It contains no explicit continuation.  The continuation is obtained from its
CBV evaluation context when the request becomes exposed.

The free-row rule is

$$
\frac{\Gamma\vdash V:P_i}
     {\Gamma\vdash\mathsf{op}_{\Delta,i}(V):R_i!\{\Delta\}}.
$$

Sequencing and conditionals combine rows by union.  Old base primitives have
empty *new* row, although they need not be pure in the old system.

## 3. Intended shallow matcher

For every operation in $\Delta$, the matcher contains a response clause

$$
h_i(p):R_i!\theta_i.
$$

There is no source-level resumption variable.  A clause computes the value
that will be supplied to the captured continuation.  The value fallback and
different-interface fallback are identities and may be omitted in surface
syntax.

We write

```text
shallow_Delta M with {
  op_i(p) -> H_i
}
```

where the displayed family is exhaustive for $\Delta$.

## 4. Direct operational rules

The scrutinee first evaluates through old base computation.  Since the base is
terminating, it eventually reaches a returned value, an old terminal outcome,
or an exposed free request.

The value rule is

$$
\mathsf{shallow}_\Delta(\mathsf{return}\;V,h)
\longrightarrow
\mathsf{return}\;V.
\tag{S-Ret}
$$

Suppose the first free request is matching:

$$
E[\mathsf{op}_{\Delta,i}(V)].
$$

Then

$$
\mathsf{shallow}_\Delta(E[\mathsf{op}_{\Delta,i}(V)],h)
\longrightarrow
\mathbf{let}\ r\leftarrow H_i[V/p]\ \mathbf{in}\ E[\mathsf{return}\;r].
\tag{S-Match}
$$

The continuation $E$ is resumed exactly once and is not wrapped in
$\mathsf{shallow}_\Delta$ again.

For the first free request from $\Gamma\neq\Delta$, the matcher terminates and
forwards that request with its original continuation:

$$
\mathsf{shallow}_\Delta(E[\mathsf{op}_{\Gamma,j}(V)],h)
\longrightarrow
E[\mathsf{op}_{\Gamma,j}(V)].
\tag{S-Other}
$$

This is a **first-free-boundary matcher**, not a searching catch.  If a
$\Gamma$ request occurs before a later $\Delta$ request, the latter is not
reached by this matcher.

## 5. Finite behavior trees

For the proof, expose base boundaries intensionally.  The well-founded behavior
tree is generated by

$$
\begin{aligned}
t::={}&\mathsf{ret}(a)\\
&\mid\mathsf{base}_\beta(p,r\mapsto t_r)\\
&\mid\mathsf{free}_{\Delta,i}(p,r\mapsto t_r).
\end{aligned}
$$

If a concrete base machine internally executes some primitive, its normalized
tree may quotient or accumulate the corresponding base nodes.  The generic
proof uses the explicit tree; a typed fold later maps it to the chosen base
model.

Return and substitution give these trees their usual free-monad structure.
Adding $\Sigma$ therefore preserves the finite substitution/monad structure
independently of the handler.

## 6. Tree shallow transformation

Define $\mathsf{sh}_{\Delta,h}$ by recursion only while searching through base
boundaries:

$$
\mathsf{sh}_{\Delta,h}(\mathsf{ret}(a))=\mathsf{ret}(a),
$$

$$
\mathsf{sh}_{\Delta,h}(\mathsf{base}_\beta(p,k))
=
\mathsf{base}_\beta(p,r\mapsto\mathsf{sh}_{\Delta,h}(k(r))),
$$

$$
\mathsf{sh}_{\Delta,h}(\mathsf{free}_{\Delta,i}(p,k))
=
\llbracket H_i[p/x]\rrbracket\mathbin{\gg=}k,
$$

and, for $\Gamma\neq\Delta$,

$$
\mathsf{sh}_{\Delta,h}(\mathsf{free}_{\Gamma,j}(p,k))
=
\mathsf{free}_{\Gamma,j}(p,k).
$$

The absence of a recursive call on $k$ in the last two equations is precisely
shallowness.  The matching equation substitutes one response and continues
with the bare tail; the other-interface equation stops at the first free
boundary.

## 7. Safe row transformer

Let the input computation have may-row $\rho$, and let

$$
\theta=\bigcup_i\theta_i
$$

bound the free operations emitted by response clauses.  A uniformly sound
output is

$$
\rho\cup\theta.
\tag{Row-Shallow}
$$

In general we cannot subtract $\Delta$.  Even after the first matching
$\Delta$ is replaced, the bare continuation may contain another $\Delta$.
The static row records possibility, not which occurrence is first or how many
remain.

## 8. What kind of structure the matcher is

The free-operation extension is a monad construction.  The shallow matcher is
not generally a monad morphism.  In particular, a matcher that changes the
response of an operation can distinguish
$\mathsf{sh}(M\mathbin{\gg=}f)$ from
$\mathsf{sh}(M)\mathbin{\gg=}(\mathsf{sh}\circ f)$.  In the first term a
matching request in $M$ ends the matcher before $f$ runs; in the second term a
fresh matcher is applied to $f$.

The appropriate claim is therefore:

> $\mathsf{sh}_{\Delta,h}$ is a typed, result-natural first-boundary tree
> transformation satisfying the four operational equations.

Monad preservation belongs to the extension constructor, not to the handler.
